# Little Anti-Cheat

Plugin anti-trampas para juegos del motor Source. Este fork mantiene el trabajo original de **J_Tanzanite**, con foco en Left 4 Dead 2.

## Instalación

Instala SourceMod y extrae el ZIP de [GitHub Releases](https://github.com/AoC-Gamers/Little-Anti-Cheat/releases) en el directorio del juego. El paquete incluye el plugin, las traducciones y el include público.

Consulta [detecciones, compatibilidad e integración](docs/detections/README.md) y las [notas del autor original](docs/project/README.md).
